# Slides

Public, speaker-notes-stripped HTML builds of my conference talks — served at
[gabrielebartolini.it/slides](https://gabrielebartolini.it/slides) via
GitHub Pages.

This repository holds generated output only. The source — Markdown decks,
themes, speaker notes — lives in a private repository and is built here with
`make publish` (see that repo's `CLAUDE.md` for the theme and authoring
conventions, and its `Makefile` for the `publish` / `publish-deck` /
`publish-index` targets). Don't hand-edit anything here; it gets overwritten
on the next publish.
